# Response Mock - 浏览器 API 拦截插件

一个轻量的 Chrome 浏览器扩展，基于 Manifest V3 构建，用于拦截并修改指定 URL 接口的响应数据，方便前端开发调试和接口 Mock 测试。

---

## 功能特性

- **规则管理** — 创建、编辑、删除、启用/禁用拦截规则
- **通配符匹配** — 支持 `*` 通配符匹配 URL 路径，如 `*/api/users/*`
- **方法过滤** — 支持 GET / POST / PUT / DELETE / PATCH 等 HTTP 方法
- **自定义响应** — 自定义 HTTP 状态码、响应体（JSON）、响应头
- **响应延迟** — 设置延迟时间，模拟慢速网络
- **页面浮层提示** — 拦截请求后在页面右下角显示实时提示
- **拦截日志** — 实时查看已拦截/通过的请求记录
- **导入/导出** — 规则支持 JSON 格式备份和恢复
- **持久化存储** — 使用 Chrome 本地存储保存规则和日志

## 安装方式

### 开发模式（推荐）

1. 克隆或下载本项目到本地目录
2. 打开 Chrome，进入 `chrome://extensions/`
3. 开启右上角「开发者模式」
4. 点击「加载已解压的扩展程序」
5. 选择项目中的 `src` 目录

### 固定图标

如果扩展图标显示为灰色方块，需要为每种尺寸的 PNG 图标补充数据（当前为占位图）。替换 `src/assets/` 目录下的图标文件即可。

## 使用方法

### 1. 添加拦截规则

点击插件图标 → 点击「添加规则」→ 填写配置：

| 字段 | 说明 |
|------|------|
| 规则名称 | 规则的显示名称 |
| HTTP 方法 | 匹配的方法（选择「全部」则不限制方法）|
| URL 匹配 | 支持 `*` 通配符，如 `*/api/user/*` |
| 响应状态码 | HTTP 状态码，如 200 / 404 / 500 |
| 响应延迟 | 延迟时间（毫秒），模拟慢速网络 |
| 响应体 | JSON 格式的响应数据 |

### 2. 启用规则

规则默认启用。点击规则列表中的开关可以随时启用/禁用规则。

### 3. 测试拦截

打开任意网页，访问匹配的 URL 接口。如果请求被拦截：
- 页面右下角会显示浮层提示（MOCKED）
- 响应数据会被替换为规则中配置的 Mock 数据

### 4. 查看日志

点击插件图标 → 「设置」→ 「拦截日志」，可查看所有拦截记录。

## 技术细节

- **Manifest V3** — 使用 Chrome 最新扩展规范
- **拦截原理** — 通过重写页面内的 `window.fetch` 和 `XMLHttpRequest` 实现拦截
- **数据存储** — 使用 `chrome.storage.sync` 存储规则配置
- **无框架依赖** — 纯 HTML + CSS + Vanilla JS 构建

## 常见问题

**Q: 为什么图标显示为灰色方块？**
> 图标使用了程序生成的占位 PNG 文件。替换 `src/assets/` 下的图标为真实图标即可。

**Q: 为什么某些网站的请求没有被拦截？**
> 插件在页面加载时注入内容脚本。某些在注入前已发送的请求（如关键渲染路径资源）无法拦截。另外，服务端直连（如非浏览器请求）无法通过客户端脚本拦截。

**Q: 如何拦截 WebSocket 请求？**
> 当前版本不支持 WebSocket 拦截，可通过其他工具（如 Proxyman、Charles）实现。

**Q: 规则如何同步到其他设备？**
> 规则存储在 Chrome Sync 中，登录同一 Google 账号即可自动同步。
