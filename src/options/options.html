关于

Response Mock v1.0.0

一个轻量的浏览器扩展，用于拦截和修改 API 响应数据。

基于 Chrome Manifest V3 构建

添加规则

支持 * 作为通配符，例如 */api/users/* 匹配所有用户相关接口
设置响应延迟，用于模拟慢速网络或测试加载状态
